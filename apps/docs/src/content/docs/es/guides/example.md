---
title: Guía de ejemplo
description: Una guía de ejemplo que recorre una tarea.
---

Las guías enseñan a completar una tarea. Agrega un archivo Markdown en `src/content/docs/es/guides/` y aparecerá en la barra lateral automáticamente.

:::tip
Empieza cada guía con el resultado que obtiene quien la lee.
:::

1. Describe lo que se necesita antes de empezar.
2. Recorre cada paso en orden.
3. Muestra cómo confirmar que funcionó.
