description: Una página de referencia de ejemplo para opciones de configuración.
---

Las páginas de referencia enumeran detalles exactos. Agrega un archivo Markdown en `src/content/docs/es/reference/` y aparecerá en la barra lateral automáticamente.

| Opción    | Tipo      | Valor predeterminado | Descripción                               |
| --------- | --------- | -------------------- | ----------------------------------------- |
| `enabled` | `boolean` | `true`               | Activa o desactiva la función.            |
| `timeout` | `number`  | `5000`               | Milisegundos que se espera una respuesta. |
