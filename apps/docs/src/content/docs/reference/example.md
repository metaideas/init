Reference pages list exact details. Add a Markdown file to `src/content/docs/reference/` and it appears in the sidebar automatically.

| Option    | Type      | Default | Description                       |
| --------- | --------- | ------- | --------------------------------- |
| `enabled` | `boolean` | `true`  | Turns the feature on or off.      |
| `timeout` | `number`  | `5000`  | Milliseconds to wait for a reply. |
