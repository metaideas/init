---
title: Example Guide
description: A sample guide that walks through one task.
---

Guides teach a reader how to finish one task. Add a Markdown file to `src/content/docs/guides/` and it appears in the sidebar automatically.

:::tip
Start each guide with the outcome the reader gets.
:::

1. Describe what the reader needs before they start.
2. Walk through each step in order.
3. Show how to confirm that it worked.
