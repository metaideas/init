  <h1 align="center"><code>@init/ai</code></h1>
</div>

AI integration package with framework-specific client and helper entrypoints.

- `@init/ai/react/ai-sdk` exports the AI SDK React client.
- `@init/ai/react/tanstack-ai` exports the TanStack AI React client.
- `@init/ai/helpers/ai-sdk` exports scripted AI SDK chat helpers.
- `@init/ai/helpers/tanstack-ai` exports scripted TanStack AI chat helpers.
- `@init/ai/registry` exports the model provider registry for server-side AI calls.
