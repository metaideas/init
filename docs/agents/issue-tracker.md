# Issue tracker: GitHub

Issues and PRDs for this template live in the `metaideas/init` GitHub repository. Use
the GitHub CLI or connected GitHub tools for tracker operations and infer the repository
from the local Git remote.

## Conventions

- Read the issue body and comments before acting.
- Use conventional, outcome-focused issue titles.
- Preserve the issue's existing labels unless triage requires a deliberate change.
- Link pull requests and follow-up issues to the originating issue.
- Publish implementation plans as issues when an agent workflow asks for the project
  issue tracker.

This file is upstream wiring. `bun template setup` removes it so scaffold owners can
configure their own tracker.
